INFINITE UNIVERSE — ANDROID TEST v0.1

Это исходный Android Studio проект для сборки APK. Готового APK в архиве нет.

Сборка:
1. Установите Android Studio с Android SDK 35 и JDK 17.
2. Откройте папку InfiniteUniverseAndroid как проект.
3. Дождитесь Gradle Sync (Android Studio предложит загрузить Gradle).
4. Build > Build Bundle(s) / APK(s) > Build APK(s).
5. APK: app/build/outputs/apk/debug/app-debug.apk
6. Перенесите APK на телефон и установите.

Приложение использует локальный WebView, не требует интернета и ПК при работе.
Это демо-интерфейс с анимацией и рандомайзером, а НЕ настоящие системные живые обои.
SpaceEngine и Gaia Sky пока не подключены; названия обозначают режимы демонстрации.

Сборка не проверена в этой среде: Android SDK и Gradle отсутствуют.
